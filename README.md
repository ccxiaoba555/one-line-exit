A night guard at a wax museum resigns in a single line — the figures started clocking in early, and one of them handed him the letter:

> Dear boss, I resign as night guard at the wax museum: the figures started clocking in early, and last night one handed me this letter.

The program writes that single line to `/output/entry.txt` for make.fun's "The One-Line Exit" bounty. It self-checks the 1–140 character gate and single-line rule before writing, then reads the file back to verify it landed byte for byte.

## Run it

```sh
python3 main.py
```
